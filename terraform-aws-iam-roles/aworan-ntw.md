UBUNTU STEP BY STEP INSTALLATION

Here are how to install  Ubuntu on the Windows server sir. You can download everything either from your Mac or directly from the Windows server. All you need is a microSD card or a flash drive that you can use to create a bootable USB.

Step 1: Get the flash drive or microSD card .

Step 2: Download the latest Ubuntu ISO  for either AMD or Intel processors from: https://ubuntu.com/download/desktop

Step 3: Create a bootable USB using one of these tools:
* Use balenaEtcher if you’re using your Mac: https://etcher.balena.io/
* Use Rufus if you’re using the Windows machine: https://ubuntu.com/tutorials/create-a-usb-stick-on-windows#2-requirements
Here is a detailed guidance, you can check: https://ubuntu.com/tutorials/create-a-usb-stick-on-windows

Step 4: Once your bootable USB is ready, follow the installation steps here: https://ubuntu.com/tutorials/install-ubuntu-desktop#1-overview
